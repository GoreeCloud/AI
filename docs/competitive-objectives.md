# GoreeCloud AI — Competitive Objectives

GoreeCloud AI aims to converge the *capabilities*, not copy the user interfaces or source code, of LibreChat, Open WebUI and AnythingLLM. Their official feature documents inform future interoperability research; all third-party code and branding require separate license and provenance review.

| Objective | Baseline | Future acceptance criteria |
| --- | --- | --- |
| Unified local chat | Ollama API with basic UI | Streaming, resumable history and context controls |
| Smart Model | Heuristic Qwen/Gemma routing | Configurable profiles, quality evaluation and explainable fallback |
| Workspaces and knowledge | Local chat persistence only | Scoped spaces, source-grounded RAG and retention |
| Agents and tools | Not implemented | Isolated skills, permission enforcement and tested workflows |
| Multimodal | Not implemented | Verified vision, speech and image workflows |
| Automations | Not implemented | Durable jobs with audit and cancellation |
| Collaboration | Not implemented | Identity-based scoped roles and sharing |
| Privacy & security | Local-first prototype | Verified GoreeShield / Wardveil integration |
| Design | Functional generic responsive UI | Verified centralized GoreeCloud UI components |
| Portability | Docker and Python scaffolding | Tested installable platform-specific packages |

This document records objectives and is not a feature parity or release claim.
